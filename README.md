# Welcome to my... wait Cat Shop)?

A very serious cat store where you start with 30 coins and try to buy cats.
I said try. ╰(*°▽°*)╯

## How to run
```bash
python cat_shop.py
```

## The cats

| Cat | Price | Risk level |
|-----|-------|------------|
| Normal cat | 5 coins | None, it's just a cat |
| Explosive cat | 10 coins | The name should tell you enough |
| Mysterious cat | 15 coins | Breaks the entire store. You get kicked out. |

## How it ends
- You run out of money → kicked out
- You buy the mysterious cat → also kicked out (and -500 coins somehow)
- There is no winning
